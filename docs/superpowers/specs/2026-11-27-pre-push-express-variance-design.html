เทียบผลต่างก่อนส่ง Express

Date: 2026-11-27 Owner: StockCount Pro Scope: Pre-push compare — ยอดนับแอป vs LOCBAL สด จาก STLOC

Goals / Non-goals

Goals

  • ให้ตรวจ ก่อนส่งยอดเข้า Express ว่าผลต่างที่คาดจะเป็นเท่าไร
  • สูตร: ผลต่างที่คาด = ยอดนับในแอป (ที่จะส่ง) − LOCBAL สด
  • ดึง LOCBAL สดจาก Express DBF (STLOC) ผ่าน FastAPI + Next proxy
  • แยกชัดจากรายงานหลังอยู่ใน Express (PHYBAL − LOCBAL) และจากหน้าขอนับใหม่

Non-goals

  • ไม่บังคับต้องดึงก่อนถึงจะกดส่ง Express (ยังส่งจากรายการเอกสารได้)
  • ไม่เขียน PHYBAL / ไม่แก้ STTAK ในหน้านี้
  • ไม่แทนที่รายงานหลัง Express ที่มีอยู่แล้วในงานนี้ (คงปุ่มคนละความหมาย)
  • ไม่ดึงผ่าน Pode ExpressAPI

Current state

  • มีรายงาน /supervisor/documents/[id]/express-variance ที่ดึง STTAK3 หลังมีข้อมูลใน Express — ไม่ตอบโจทย์ก่อนส่ง
  • FastAPI variance อ่าน STTAK+STLOC ได้แล้ว แต่ยังไม่มี endpoint เฉพาะ LOCBAL
  • การส่ง Express อยู่ที่อนุมัติ / ปุ่มส่งมือบนแท็บเสร็จสิ้น

User workflow

  1. Supervisor+ เปิดรายการเอกสาร (รอตรวจหรือเสร็จสิ้น)
  2. กดปุ่ม เทียบก่อนส่ง Express ของใบนั้น
  3. เข้าหน้า /supervisor/documents/[documentId]/pre-push-variance
  4. อ่านคำอธิบาย แล้วกด ดึงคงเหลือ Express
  5. ดูตาราง: นับได้ (แอป) vs คงเหลือสด vs ผลต่างที่คาด
  6. กลับรายการเอกสาร แล้วค่อยอนุมัติ/ส่ง Express ตามปกติ

Data model / API

FastAPI (ใหม่)

GET /api/stockcount/locations/{locationCode}/balances
Authorization: Bearer {VARIANCE_API_TOKEN}

อ่าน STLOC.DBF ของบริษัท (เช่น 240BKK3) กรอง LOCCOD = location

{
  "success": true,
  "locationCode": "2425",
  "fetchedAt": "2026-11-27T09:00:00.000Z",
  "balances": [
    { "ProductCode": "1010030003", "LocationBalance": 7483.0 }
  ]
}
  • ไม่มีแถวในคลัง → 404 หรือ balances: [] (เลือก: คืน 200 + ว่าง แล้ว UI แสดงไม่พบต่อ SKU)
  • แนะนำ: 200 + รายการที่มีจริง; SKU ในแอปที่ไม่มีใน map = ไม่พบคงเหลือ

Next.js proxy

GET /api/count-documents/[documentId]/pre-push-variance
Cookie session (Supervisor+ + document access)
  1. โหลดเอกสาร + บรรทัดนับ (ยอดที่จะส่ง = totalBaseQty / effective entry)
  2. เรียก FastAPI balances ด้วย locationCode
  3. แมปด้วย productCode; คำนวณ projectedDiff
  4. คืน JSON ให้ UI (หรือแยก context + fetch balances เป็น 2 ขั้นเหมือนเดิมก็ได้)

แนะนำ UX: หน้าโหลด context ก่อน (ไม่เรียก Express) แล้วปุ่มดึงค่อยเรียก balances — ไม่ auto-fetch
