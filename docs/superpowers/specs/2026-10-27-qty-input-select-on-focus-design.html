เลือกทั้งช่องจำนวนตอนโฟกัส

Date: 2026-10-27 Owner: StockCount Pro Scope: QtyInput บน /tablet/count/[documentId] · Counter / Supervisor

Goals / Non-goals

Goals

  • แตะช่องจำนวนแล้วพิมพ์เลขใหม่ได้ทันที โดยไม่ต้องลบ 0 หรือตัวเลขเดิมก่อน
  • ถ้าแตะแล้วออกโดยไม่พิมพ์ ค่าเดิมยังอยู่ ไม่ยิงบันทึกใหม่

Non-goals

  • ไม่ซ่อนเลข 0 บนจอเมื่อยังไม่ได้โฟกัส
  • ไม่เปลี่ยนความหมายของ 0 / -1 / ช่องว่าง
  • ไม่แตะเครื่องคิดเลขแพ๊ค→ชิ้น คิวบันทึก หรือ API

Current state

  • QtyInput แสดงค่าจริงในช่อง รวมถึง 0
  • ตอนโฟกัสเคอร์เซอร์อยู่ท้ายข้อความ พิมพ์ต่อท้ายหรือต้องลบก่อน
  • ยังไม่นับเป็นช่องว่างพร้อม placeholder —

User workflow

  1. ผู้ใช้นับเห็นช่องลังเป็น 0 (หรือจำนวนอื่น)
  2. แตะช่อง → ข้อความทั้งช่องถูกเลือก
  3. พิมพ์จำนวนใหม่ เช่น 5 → แทนค่าเดิมทันที
  4. ออกจากช่อง → commit ตามเดิม (debounce / คิวบันทึกไม่เปลี่ยน)
  5. ถ้าแตะแล้วออกโดยไม่พิมพ์ → ค่าเดิมยังอยู่ ไม่เรียก onChange
