FastAPI — Express Stock Count Variance API

Date: 2026-11-27 Owner: StockCount Pro Scope: Phase 1 — FastAPI เฉพาะ variance ที่ external/express-variance-api/

Goals / Non-goals

Goals

  • สร้างบริการ FastAPI อ่านผลต่างตรวจนับแบบ Express STTAK3
  • คืน PhysicalBalance, LocationBalance, DifferentQty ต่อวัน + คลัง
  • Auth MVP ด้วย Bearer token คงที่จาก .env (VARIANCE_API_TOKEN)
  • แยกจาก Pode ExpressAPI — ไม่แก้ OneDrive ต้นทาง

Non-goals

  • ไม่ย้าย ExpressAPI ทั้งก้อนไป FastAPI
  • ยังไม่ผูก StockCount Pro UI / Next.js proxy (Phase 2)
  • ยังไม่ใช้ login ของ Pode เป็นแหล่ง token
  • ยังไม่ dual-unit STTAKD / post ปรับยอด / รายงาน 465
  • ไม่ลบ prototype PowerShell บน branch feature/express-stockcount-variance ในรอบนี้ (เส้นทางหลักคือ FastAPI)

Current state

  • สูตร Express: DIF = STTAK.PHYBAL − STLOC.LOCBAL กรอง TAKFLG ∈ {'2','3'}
  • มี design/plan ของ Pode variance แล้ว และมี prototype บน worktree — แต่ตัดสินใจทำ FastAPI เฉพาะ variance แทนเป็นเส้นทางหลัก
  • StockCount Pro ยังคำนวณผลต่างจาก snapshot ตอน sync ไม่ใช่ LOCBAL สด
  • การเข้าถึงแชร์ Express อาจติด credential — API ต้อง configurable ผ่าน EXPRESS_DB_PATH

User workflow

  1. ตั้งค่า EXPRESS_DB_PATH และ VARIANCE_API_TOKEN ใน .env
  2. รัน FastAPI (uvicorn app.main:app)
  3. เรียก GET variance พร้อม Authorization: Bearer …
  4. ได้ JSON สำหรับเทียบ / ใช้ใน Phase 2 จาก StockCount Pro

Data model / API

Endpoint

GET /api/stockcount/variance/countdate/{yyyy-MM-dd}/locations/{codes}
Authorization: Bearer {VARIANCE_API_TOKEN}

Environment

ตัวแปรความหมาย
EXPRESS_DB_PATHโฟลเดอร์บริษัท Express ที่มี STTAK.DBF / STLOC.DBF / STMAS.DBF
VARIANCE_API_TOKENBearer token สำหรับเรียก API (ต้องไม่ commit ค่าจริง)
HOST / PORToptional — ค่าเริ่มต้น localhost:8090 (ไม่ชน Pode 8080)

สูตรและฟิลด์

JSONที่มา
LocationCodeSTTAK.LOCCOD
ProductCodeSTTAK.STKCOD
ProductNameSTMAS.STKDES
AreaSTLOC.AREA fallback STTAK.AREA
CountDateSTTAK.TAKDAT → yyyy-MM-dd
PhysicalBalanceSTTAK.PHYBAL
LocationBalanceSTLOC.LOCBAL สด
DifferentQtyPhysicalBalance − LocationBalance
CountFlagSTTAK.TAKFLG

Filter: TAKFLG เป็น 2 หรือ 3, TAKDAT ตรงวันที่, LOCCOD อยู่ในรายการที่ขอ

ไม่มีแถว STLOC: คืนแถว STTAK โดย LocationBalance = null, DifferentQty = null

การอ่าน DBF

  • รอบแรกใช้ไลบรารี Python อ่าน DBF โดยตรง (เป้าหมาย: ไม่บังคับ VFPOLEDB)
  • ถ้าฟิลด์ binary/encoding ของ Express อ่านไม่ครบ ให้ปรับใน variance.py เป็นชั้นเดียว ไม่เปลี่ยนสัญญา API

Test checklist

  • □ unit: วันที่ / รหัสคลัง / สูตร diff รวมกรณี null
  • □ auth: ไม่มี token → 401, token ถูก → ผ่าน
  • □ 404 เมื่อไม่มีข้อมูล
  • □ smoke กับ EXPRESS_DB_PATH จริงเมื่อมีสิทธิ์เข้าถึงแชร์
  • □ ไม่ commit ค่า token / ไม่แก้ OneDrive ExpressAPI
  • □ พอร์ตไม่ชน Pode (ค่าเริ่ม 8090)
