Express Stock Count Variance API

Date: 2026-11-27 Owner: StockCount Pro / ExpressAPI Scope: Phase 1 — API ใน external/ExpressAPI เท่านั้น

Goals / Non-goals

Goals

  • เพิ่ม endpoint อ่านผลต่างการตรวจนับแบบ Express รายงาน STTAK3
  • คืนรายการต่อวัน + คลัง: PhysicalBalance, LocationBalance, DifferentQty
  • ให้ StockCount Pro ดึงมาเทียบในเฟสถัดไปได้ โดยไม่ต้องเปิด ExpressI พิมพ์รายงานทุกครั้ง
  • แก้เฉพาะสำเนาในโปรเจกต์ (external/ExpressAPI) — ไม่แตะ OneDrive ต้นทาง

Non-goals (รอบนี้)

  • ยังไม่ผูก UI / proxy ใน StockCount Pro (Phase 2)
  • ยังไม่ทำ dual-unit แบบรายงาน STTAKD
  • ยังไม่ Post Physical Count / ปรับยอด / เขียน DBF
  • ยังไม่ทำรายงานเมนู 465 (STTAKX จาก STTRN)
  • ยังไม่รวม stockcount sync/push อื่นที่ยังไม่มีในสำเนา API นี้

Current state

  • ExpressI คำนวณผลต่างตอนพิมพ์ STTAK3: DIF = STTAK.PHYBAL − STLOC.LOCBAL กรอง TAKFLG ∈ {'2','3'}
  • StockCount Pro sync ใช้ GET /api/stockcount/locations/countdate/{date} และ GET /api/stockcount/countdate/{date}/locations/{codes} จากเซิร์ฟเวอร์ Express อื่น — สำเนา external/ExpressAPI ยังไม่มี route กลุ่ม stockcount
  • หน้า review ในแอปคำนวณ totalBaseQty − expectedQty จาก snapshot ตอน sync — อาจไม่เท่า STTAK3 ถ้า LOCBAL เปลี่ยนหลัง sync
  • ฟิลด์ DifferentQty จาก Express stock-count line มีใน type แต่ยังไม่ใช่แหล่งความจริงของรายงานผลต่าง

User workflow

  1. ผู้ใช้ (หรือ StockCount Pro ภายหลัง) login ExpressAPI ได้ Bearer token
  2. เรียก variance endpoint ด้วยวันที่นับ + รหัสคลัง (หนึ่งหรือหลายคลังคั่นด้วย comma)
  3. API อ่าน STTAK ของวัน/คลังที่นับแล้ว แล้วอ่าน STLOC.LOCBAL สด
  4. คำนวณ DifferentQty = PhysicalBalance − LocationBalance ต่อบรรทัด
  5. คืน JSON ให้ client นำไปเทียบ / แสดงผล (Phase 2: หน้า review หรือแผงเทียบหลัง push)

Data model / API

Endpoint

GET /api/stockcount/variance/countdate/{yyyy-MM-dd}/locations/{codes}
Authorization: Bearer {token}
  • {yyyy-MM-dd} — วันที่นับ (= STTAK.TAKDAT)
  • {codes} — รหัสคลังคั่นด้วย comma ใน path เช่น 24A1,24GA (ไม่ encode comma เป็น %2C)
  • Auth บังคับเหมือน route อื่นของ ExpressAPI

สูตรและแหล่งข้อมูล

ฟิลด์ JSONที่มา
LocationCodeSTTAK.LOCCOD
ProductCodeSTTAK.STKCOD
ProductNameSTMAS.STKDES
AreaSTLOC.AREA (fallback STTAK.AREA)
CountDateSTTAK.TAKDAT เป็น yyyy-MM-dd
PhysicalBalanceSTTAK.PHYBAL
LocationBalanceSTLOC.LOCBAL (อ่านสด)
DifferentQtyPhysicalBalance − LocationBalance
CountFlagSTTAK.TAKFLG

Filter: TAKFLG = '2' OR TAKFLG = '3' และ LOCCOD อยู่ในรายการที่ขอ และ TAKDAT ตรงวันที่

Join: STLOC บน STKCOD + LOCCOD · STMAS บน STKCOD

ถ้าไม่มีแถว STLOC: ยังคืนแถวจาก STTAK โดยตั้ง LocationBalance = null และ DifferentQty = null (ไม่ drop แถว)

Test checklist

  • □ Login ได้ token แล้วเรียก variance สำเร็จ
  • □ คลังที่มี TAKFLG=3 คืน PHYBAL / LOCBAL / diff ถูกต้อง
  • □ กรองออกแถว TAKFLG=1 (ยังไม่นับ)
  • □ หลายคลังใน path คืนเฉพาะคลังที่ขอ
  • □ วัน/คลังไม่มีข้อมูล → 404
  • □ date หรือ locations ผิดรูป → 400
  • □ ไม่มี Bearer → 401
  • □ สุ่ม 2–3 SKU เทียบตัวเลขกับรายงาน STTAK3 ใน ExpressI (ผลต่างตรงกัน ณ เวลาใกล้เคียง)
  • □ ไม่ได้แก้ไฟล์ใน OneDrive ต้นทาง — เปลี่ยนเฉพาะ external/ExpressAPI
