หน้ารายงานผลต่าง Express ต่อเอกสาร

Date: 2026-11-27 Owner: StockCount Pro Scope: ย้าย UX เทียบ Express ออกจากตารางรีวิวไปหน้าแยกของเอกสาร

Goals / Non-goals

Goals

  • แยก flow อนุมัติ/ขอนับใหม่ ออกจาก รายงานผลต่าง Express เพื่อไม่ให้งง
  • สื่อชัดว่าหน้านี้แสดงยอดที่ อยู่ใน Express แล้ว ไม่ใช่ยอดที่จะส่งจากแอป
  • เข้าถึงจากเอกสารเดิม: วัน + คลัง + รายการสินค้าของเอกสาร
  • ใช้ proxy FastAPI เดิม ไม่เปลี่ยนสูตร

Non-goals

  • ไม่สร้างเมนูหลักใหม่ใน sidebar
  • ไม่ทำหน้าตรวจก่อนส่ง Express ในงานนี้
  • ไม่แก้ FastAPI / สูตร STTAK3
  • ไม่ auto-fetch ตอนเปิดหน้า

Current state

  • ปุ่ม + คอลัมน์ Express ฝังใน /supervisor/review/[documentId] ทำให้ปนกับ flow อนุมัติ
  • API พร้อมแล้ว: GET /api/count-documents/[documentId]/express-variance
  • ผู้ใช้เข้าใจผิดว่าเป็นการตรวจก่อนส่งเข้า Express

User workflow

  1. Supervisor+ เปิดหน้ารีวิวเอกสาร
  2. กดลิงก์/ปุ่มรอง รายงานผลต่าง Express (ไม่ใช่ปุ่มหลักอนุมัติ)
  3. เข้าหน้า /supervisor/review/[documentId]/express-variance
  4. อ่านคำอธิบายสั้น แล้วกด ดึงรายงานผลต่างจาก Express
  5. ดูตารางฝั่งแอป vs ฝั่ง Express · กลับหน้ารีวิวเมื่อเสร็จ

Data model / API

  • ใช้ endpoint เดิม: GET /api/count-documents/[documentId]/express-variance
  • หน้าใหม่โหลด review lines จาก API รีวิวเดิม (หรือ endpoint ที่หน้า review ใช้อยู่) เพื่อคอลัมน์ฝั่งแอป

  • สร้าง src/app/supervisor/review/[documentId]/express-variance/page.tsx
