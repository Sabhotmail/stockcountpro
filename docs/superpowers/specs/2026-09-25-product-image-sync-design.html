Product Image Sync (อ่านอย่างเดียวจาก SalesTools)

Date: 2026-09-25 Owner: StockCount Pro Scope: Sync รูปสินค้าไป public/products ใช้ร่วมห้องของจริง (:3002) และ NKR (:3003)

Goals / Non-goals

Goals

  • คัดลอกรูปจากโฟลเดอร์ SalesTools เข้า StockCount อัตโนมัติวันละครั้ง
  • รันมือได้เมื่อมีรูปใหม่
  • ห้องของจริง (:3002) และ NKR (:3003) ใช้ชุดรูปเดียวกัน
  • ชื่อไฟล์ {รหัสสินค้า}.jpg ตรงกับ /products/{รหัส}.jpg ในแอป

Non-goals

  • ไม่เขียน / ลบ / แก้ไฟล์ในโฟลเดอร์ SalesTools เด็ดขาด
  • ไม่ใช้ junction / symlink ไปที่ต้นทาง
  • ไม่ลบรูปใน public/products เมื่อต้นทางไม่มีไฟล์นั้น
  • ไม่มีปุ่ม sync ใน UI รอบนี้
ห้ามกระทบ SalesTools: ต้นทาง C:\inetpub\wwwroot\DBO_SIRIPRO_WEB\pictures เป็นโฟลเดอร์ของระบบอื่น — สคริปต์อ่านอย่างเดียวเท่านั้น

Current state

  • UI โหลดรูปจาก /products/{รหัส}.jpg|.jpeg|.png|.webp ผ่าน src/lib/product-image.ts
  • public/products/ ถูก gitignore — ต้องมีไฟล์บนเครื่องเซิร์ฟเวอร์เอง
  • ยังไม่มีสคริปต์ sync อัตโนมัติ

User workflow

  1. รัน scripts\sync-product-images.bat ครั้งแรกเพื่อ copy ชุดปัจจุบัน
  2. รัน scripts\install-product-image-sync-task.bat ในฐานะ Administrator
  3. Task Scheduler รันทุกวัน 06:00 อัตโนมัติ
  4. เมื่อมีรูปใหม่กลางวัน — รัน sync-product-images.bat มือได้ทันที
  5. ตรวจหน้านับสต็อกทั้ง :3002 และ :3003 ว่ารูปขึ้น
SalesTools pictures → robocopy /XO (อ่านอย่างเดียว) → public/products → :3002 + :3003

Error handling & test checklist

  • ต้นทางไม่มีโฟลเดอร์ → exit 1 พร้อมข้อความชัด ไม่แตะปลายทาง
  • robocopy exit 0–7 = สำเร็จ (มาตรฐาน Windows)
  • ไม่ใช้ /MIR / /PURGE
