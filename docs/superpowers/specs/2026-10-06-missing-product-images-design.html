หน้า Admin — สินค้าไม่มีรูป

Date: 2026-10-06 Owner: StockCount Pro Scope: /admin/product-images · Admin / HQ

Goals / Non-goals

Goals

  • แสดงรหัสสินค้าที่อยู่ในเอกสารนับ แต่ไม่มีไฟล์ใน public/products
  • กดแถวดูเอกสารที่เกี่ยวข้อง และลิงก์ไป /admin/documents/[documentId]
  • สรุปจำนวนรหัสทั้งหมด / มีรูป / ไม่มีรูป

Non-goals

  • ไม่แตะโฟลเดอร์ SalesTools
  • ไม่มีปุ่ม sync รูปใน UI รอบนี้
  • ไม่อัปโหลดรูปจากหน้านี้

Current state

  • รูปเสิร์ฟจาก /products/{รหัส}.jpg|.jpeg|.png|.webp
  • sync ด้วยสคริปต์ bat เข้า public/products ต่อโฟลเดอร์ห้อง
  • ยังไม่มีหน้ารายงานรหัสที่ขาดรูป

User workflow

  1. Admin เปิดเมนูงานหลัก → รูปสินค้า
  2. ดูสรุปจำนวน และรายการรหัสที่ไม่มีรูป
  3. ค้นหารหัส/ชื่อได้
  4. กดแถวขยายรายการเอกสาร → เปิดหน้ารายละเอียดเอกสาร
  5. ไปเติมรูปที่ SalesTools แล้วรัน sync bat ของห้องนั้น
