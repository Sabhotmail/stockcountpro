รีเซ็ตเอกสารเพื่อนับใหม่จาก Express

Date: 2026-10-07 Owner: StockCount Pro Scope: /admin/documents/[documentId] · Admin / HQ

Goals / Non-goals

Goals

  • ให้ Admin/HQ รีเซ็ตใบที่เริ่มนับแล้วกลับเป็น IMPORTED เพื่อ Sync Express วัน+คลังเดิมทับได้
  • ล้างจำนวนนับ / เวอร์ชัน / lock / presence ทั้งใบ
  • บังคับเหตุผล + ยืนยันรหัสเอกสาร และเขียน audit

Non-goals

  • ไม่ Sync Express อัตโนมัติในคลิกเดียว
  • ไม่เก็บ snapshot จำนวนเดิม
  • ไม่รีเซ็ต APPROVED / COMPLETED
  • ไม่เปิดให้ Supervisor

Current state

  • Express = วัน + คลัง (ไม่มีเลขเอกสารแยก) → Sync ชี้ใบเดิม
  • Sync ทับได้เฉพาะ IMPORTED; สถานะอื่นถูกข้าม
  • ลบเอกสารได้เฉพาะ IMPORTED

User workflow

  1. Admin/HQ เปิดหน้ารายละเอียดเอกสาร
  2. กดรีเซ็ต → กรอกเหตุผล + พิมพ์รหัสเอกสารยืนยัน
  3. ระบบล้างการนับ → สถานะยังไม่เริ่ม
  4. แก้ Express แล้ว Sync วัน+คลังเดิม
  5. Staff เริ่มนับใหม่

UI Details

หน้ารายละเอียดเอกสาร — /admin/documents/[documentId]

เข้าถึงได้: Admin, HQ

Action bar · สถานะกำลังนับ
สถานะ: กำลังนับ · นับแล้ว 120/400

ปุ่มแสดงเฉพาะ COUNTING / RECOUNT_REQUESTED / SUBMITTED / REVIEWING

Dialog ยืนยัน
รีเซ็ตเอกสาร?
จำนวนที่นับไว้ทั้งหมดจะถูกลบ และสถานะกลับเป็นยังไม่เริ่ม ไม่สามารถกู้คืนได้

Data model / API

  • POST /api/admin/count-documents/[documentId]/reset body: { reason, confirmDocumentNo }
  • Transaction: ลบ entries, snapshots, versions, locks, presence, recount requests, final entries (ถ้ามี) → อัปเดตเอกสารเป็น IMPORTED, version=null/0, countedLines=0, note=null
  • เก็บ product lines ไว้ (Express sync ทับเมื่อ IMPORTED)
  • AuditAction ใหม่: RESET_DOCUMENT
