เครื่องคิดเลขแปลงแพ๊ค → ชิ้น

Date: 2026-10-06 Owner: StockCount Pro Scope: /tablet/count/[documentId] · Counter / Supervisor

Goals / Non-goals

Goals

  • ให้ผู้ใช้นับเปิดเครื่องคิดเลขข้างช่องชิ้นเมื่อต้องการ
  • กรอกจำนวนแพ๊คและชิ้นต่อแพ๊คเอง แล้วใส่ผลรวมทับช่องชิ้น
  • ถ้าชื่อสินค้ามีรูปแบบ (6x12) ให้ใส่ชิ้นต่อแพ๊ค (= 12) ให้อัตโนมัติ แก้ได้
  • ใช้ flow บันทึกเดิม (lock, ยืนยันครั้งแรก, แปลงชิ้นล้นเป็นลัง, autosave)

Non-goals

  • ไม่ทำเครื่องคิดเลขเลขคณิตทั่วไป
  • ไม่จำค่าชิ้น/แพ๊คครั้งก่อนระหว่างสินค้า (แต่ดึงจากชื่อสินค้าเมื่อมี (NxM))
  • ไม่เปิดช่องแพ็คจาก Express / ไม่แก้ sync
  • ไม่บวกเพิ่มเข้าค่าชิ้นเดิม (แทนที่เท่านั้น)

Current state

  • การ์ดสินค้ามีช่องลัง / แพ็ค / ชิ้น ตาม allowCase / allowPack / allowPiece
  • Express sync ตั้ง allowPack: false — ผู้ใช้นับกรอกลัง+ชิ้นเป็นหลัก
  • มีแปลงชิ้นล้นเป็นลังอัตโนมัติผ่าน convertPieceOverflowToCase
  • ยังไม่มีเครื่องคิดเลขแปลงแพ๊ค→ชิ้น

User workflow

  1. เปิดหน้านับสินค้าบนแท็บเล็ต
  2. เลือกบรรทัดสินค้า → กดปุ่มเครื่องคิดเลขข้างช่องชิ้น
  3. กรอกจำนวนแพ๊ค และจำนวนชิ้นต่อแพ๊ค
  4. ดูผลรวมสด แล้วกด ใส่ช่องชิ้น
  5. ระบบแทนที่ค่าในช่องชิ้น แล้วเข้า path บันทึกเดิม
