เทียบผลต่าง Express บนหน้า Review

Date: 2026-11-27 Owner: StockCount Pro Scope: Phase 2 — UI + Next proxy เรียก FastAPI variance

Goals / Non-goals

Goals

  • ให้ผู้ใช้กดดึงผลต่างจาก Express แล้วเห็นเทียบคู่ขนานกับยอดนับในแอป
  • เรียกผ่าน Next.js proxy เท่านั้น — ไม่เปิด token ให้เบราว์เซอร์
  • ใช้ documentDate + locationCode ของเอกสาร แมปแถวด้วย productCode

Non-goals

  • ไม่ auto-fetch ตอนโหลดหน้า
  • ไม่แทนที่คอลัมน์ผลต่างเดิมของแอป
  • ไม่แก้สูตร FastAPI / ไม่ post ปรับยอด Express
  • ไม่บังคับมีผลต่าง ≠ 0 จึงถือว่าสำเร็จ

Current state

  • หน้า /supervisor/review/[documentId] แสดง difference = totalBaseQty − expectedQty จาก snapshot ตอน sync
  • FastAPI variance พร้อมแล้ว: GET /api/stockcount/variance/countdate/{date}/locations/{codes}
  • เอกสารมี documentDate และ locationCode สำหรับเรียก Express

User workflow

  1. Supervisor+ เปิดหน้ารีวิวเอกสารที่มี locationCode
  2. กดปุ่ม ดึงผลต่างจาก Express
  3. ระบบแสดงสถานะกำลังโหลด
  4. สำเร็จ → ตารางมีคอลัมน์ Express เพิ่ม; แสดงเวลาดึงล่าสุด
  5. ล้มเหลว → ข้อความไทยสั้นๆ + ปุ่มลองใหม่

Data model / API

Next.js proxy

GET /api/count-documents/[documentId]/express-variance
Cookie session (Supervisor+ + document access)

Server:

  1. ตรวจ session + สิทธิ์เอกสาร
  2. อ่าน documentDate (yyyy-MM-dd) และ locationCode
  3. ถ้าไม่มี locationCode → 400
  4. เรียก FastAPI:
    GET {EXPRESS_VARIANCE_API_BASE_URL}/api/stockcount/variance/countdate/{date}/locations/{locationCode}
    Header: Authorization: Bearer {EXPRESS_VARIANCE_API_TOKEN}
  5. คืน JSON ให้ UI

Error handling & test checklist

กรณีพฤติกรรม UI
401/403 จาก Nextredirect login หรือ Access denied
เอกสารไม่มี locationCodeข้อความเอกสารไม่มีคลัง Express
FastAPI 404ไม่พบข้อมูลผลต่าง…
FastAPI/เครือข่ายพังโหลดไม่สำเร็จ + ลองใหม่
env ไม่ครบตั้งค่าไม่ครบ (503 จาก API)

Test checklist

  • □ กดปุ่มแล้วเห็นคอลัมน์ Express หลังสำเร็จ
  • □ แมป productCode ถูกต้องกับ BKK3 ตัวอย่าง
  • □ สินค้าไม่มีใน Express แสดง “ไม่พบใน Express”
  • □ ไม่มี token ฝั่ง browser (ตรวจ Network tab)
  • □ ไม่มี locationCode → error ชัดเจน
  • □ ผลต่างเดิมของแอปยังแสดงเหมือนเดิม
